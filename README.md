# 🛠️ Demo Automation Framework – AutomationExercise.com

This project is a **Test Automation Framework** built using **Java, Selenium, and Cucumber (BDD)**.  
It automates key **UI workflows** on [AutomationExercise.com](https://automationexercise.com), a demo website for practicing test automation.

---

## 🚀 Features Implemented



- 🔐 **Login/Logout** – Validate authentication workflows.
- 🧑‍🤝‍🧑 **Signup** – Automate account registration.
- 🛒 **Add to Cart** – Verify items can be added/removed from the shopping cart.
- 💳 **Product Purchase** – Complete an order workflow.
- 🔍 **Product Search** – Search for products by keyword.
- 📧 **Email Subscription** – Test newsletter subscription.
- 📝 **Product Review** – Submit and validate customer reviews.
- 📩 **Contact Us** – Fill out and submit the contact form.


---

## 📂 Tech Stack

- **Language**: Java 17
- **IDE**: IntelliJ IDEA
- **Build Tool**: Maven
- **Test Runner**: JUnit with Cucumber BDD
- **UI Testing**: Selenium WebDriver
- **Logging**: Log4j2
- **Data Generation**: JavaFaker

---

## 📦 Dependencies

Main dependencies used in `pom.xml`:

- `selenium-java: 4.33.0`
- `cucumber-java: 7.23.0`
- `cucumber-junit: 7.23.0`
- `log4j-core: 2.24.3`
- `log4j-api: 2.24.3`
- `javafaker: 1.0.2`
